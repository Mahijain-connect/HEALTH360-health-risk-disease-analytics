# HEALTH360-health-risk-disease-analytics
Health360 | Comprehensive Healthcare Risk &amp; Disease Analytics — Transforming healthcare data into actionable insights through Tableau-powered visualization, disease pattern analysis, and healthcare risk assessment to uncover meaningful trends and support data-driven decision-making.

## 🎯 Project Objectives

- To analyze healthcare data effectively.
- To identify disease patterns and health risks.
- To create interactive healthcare dashboards.
- To transform raw data into meaningful insights.
- To support data-driven healthcare understanding.
